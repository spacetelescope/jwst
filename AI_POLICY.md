# Usage of Generative AI
STScI software maintainers welcome contributions, including those developed with the assistance of generative AI tools. However, the use of such tools does not change our expectations for contributor responsibility, engagement, or code quality. The following statements apply to all contributions. Pull requests that violate this policy will be closed.
1. Prohibited Tools
   - Per STScI's AI policy, certain tools are prohibited and may not be used.  This currently includes, but may not be limited to, Deepseek and Grammarly.
2. Human ownership and accountability
   - Contributors are responsible for all submitted content, regardless of whether generative AI tools were used.
   - Contributors must understand and be able to explain all changes during review and address any concerns raised by maintainers.
   - Contributors are responsible for ensuring all submitted code complies with STScI licensing, regardless of whether generative AI tools were used.
3. Disclosure
   - Committers are required to disclose in the pull request how AI tools were used to generate any part of the contribution. We encourage committers to specify which tool was used and to also apply a label of `ai-assisted` to pull requests that leveraged AI tools.
   - Presence of this `AI_POLICY.md` file indicates AI tools may have been used to assist with portions of this work.
4. Authentic engagement
   - The pull request process is collaborative and iterative. Contributors are expected to actively engage with reviewer feedback themselves. Copying and pasting replies to/from a generative AI tool does not count as engaging with the reviewer.
   - All pull requests must be reviewed by a human other than the contributor.
5. Consistency with repository conventions and existing style
   - In the context of Generative AI, this particularly means adhering to any linting standards as well as conveying information (comments, documentation, etc.) in a style the repository uses, and that is appropriate and to the point.

> [!IMPORTANT]
> Autonomous workflows ("agents") are not human contributors. Reviewers expect to interact with the human controlling the account, or we will close the PR.
